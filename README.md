Basketball Score Tracker

BAN 701 – Assignment 8: Git Development with AI

## Project Description

The Basketball Score Tracker is a Python program that allows users to enter basketball game scores and calculate basic statistics. The program helps users track their scoring performance across multiple games.

## Initial Version

The initial version of the program included the following features:

Allowed users to enter the number of basketball games.

Used a loop to collect scores for each game.

Stored game scores in a list.

Used a function to calculate the average score.

Displayed the total number of games, total points, and average points scored.

Included basic handling for entering zero or fewer games.

## AI Tool Used

ChatGPT by OpenAI was used as the AI coding assistant.

## AI Assistance

 I used ChatGPT to help improve the program by adding features that identify the highest and lowest game scores.

## New or Modified Features

The updated version of the program includes two additional calculations:

Highest Score: Displays the highest number of points scored in a game.

Lowest Score: Displays the lowest number of points scored in a game.

These features allow users to better understand their scoring performance across multiple games.

The max() and min() functions provide a simple way to identify the highest and lowest scores in a list. I chose to use these functions because they are easy to understand and fit the purpose of the program.
After making the changes, I tested the program to verify that the calculations produced the correct results.

## How to Run the Program

Download or clone the GitHub repository.
Open the project folder in Visual Studio Code.
Make sure Python is installed on the computer.
Open the terminal in Visual Studio Code.
Type python main.py and press Enter.
Enter the number of basketball games when prompted.
Enter the points scored for each game.
The program will display the total games played, total points, average score, highest score, and lowest score.
